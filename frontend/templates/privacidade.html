Política de Privacidade

Última atualização: [INSERIR_DATA_AQUI]

Aqui explicamos, sem juridiquês desnecessário, que dados o GateFlow recolhe, para que servem e como são guardados. Se em algum momento este texto parecer vago, é sinal de que precisamos de o reescrever — diz-nos.

1. Que dados recolhemos

Dependendo de como usas o GateFlow, recolhemos:

  • Se és organizador ou porteiro: nome completo, e-mail, telefone, nome de usuário e palavra-passe (guardada de forma encriptada, nunca em texto simples).
  • Se compras um bilhete: nome, e-mail e/ou telefone usados para receber o bilhete, e os dados da transação M-Pesa necessários para confirmar o pagamento (número de telemóvel usado no pagamento e valor — nunca o PIN do M-Pesa, que fica exclusivamente com a Vodacom/M-Pesa).
  • Dados de uso do sistema: registos de check-in (quem validou, quando e onde), para permitir auditoria em caso de disputa sobre entrada em evento.
  • Preferência de tema (claro/escuro): guardada só no teu próprio navegador (não é enviada para os nossos servidores).

2. Para que usamos esses dados

  • Emitir e validar bilhetes;
  • Processar pagamentos via M-Pesa e confirmar transações;
  • Enviar o bilhete e comunicações relacionadas ao evento comprado;
  • Prevenir fraude (por exemplo, detetar tentativas de reutilizar um QR Code já validado);
  • Cumprir obrigações legais, quando aplicável.

Não vendemos os teus dados a terceiros. Ponto final.

3. Com quem partilhamos dados

Partilhamos apenas o estritamente necessário, e apenas com:

  • M-Pesa / Vodacom: para processar o pagamento do bilhete ou da taxa da plataforma;
  • O organizador do evento: tem acesso à lista de compradores/convidados do próprio evento, para efeitos de gestão e check-in;
  • Autoridades competentes: apenas quando exigido por lei.

4. Onde os dados ficam guardados

Os dados são guardados em servidores geridos por nós ou por fornecedores de infraestrutura contratados para esse fim [INSERIR_DETALHE_DO_FORNECEDOR/SERVIDOR_AQUI]. Aplicamos medidas técnicas razoáveis para proteger essa informação — palavras-passe encriptadas, ligação segura (HTTPS) e controlo de acesso por perfil de utilizador.

5. Por quanto tempo guardamos os dados

Mantemos os dados de conta enquanto ela estiver ativa, e os registos de bilhetes/check-in pelo tempo necessário para efeitos de auditoria e eventuais disputas sobre um evento — normalmente [INSERIR_PRAZO_AQUI] após a realização do evento.

6. Os teus direitos

Podes, a qualquer momento, pedir-nos para:

  • Ver que dados temos sobre ti;
  • Corrigir dados desatualizados ou incorretos;
  • Apagar a tua conta e os dados associados, exceto o que formos obrigados a manter por lei ou por questões de segurança/auditoria de eventos já realizados.

Para exercer qualquer um destes direitos, escreve para tiagovbanze@gmail.com.

7. Cookies e armazenamento local

O GateFlow usa apenas armazenamento local do navegador (localStorage) para lembrar a tua preferência de tema (claro/escuro) e a tua sessão de acesso. Não usamos cookies de rastreamento publicitário nem partilhamos dados de navegação com redes de publicidade.

8. Alterações a esta política

Se mudarmos a forma como tratamos os teus dados, atualizamos esta página e a data no topo. Mudanças relevantes serão comunicadas de forma visível na plataforma.

9. Fala connosco

Qualquer questão sobre privacidade pode ser enviada para tiagovbanze@gmail.com ou pelo WhatsApp no rodapé desta página.
